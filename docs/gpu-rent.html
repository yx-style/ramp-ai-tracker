来源与口径

云厂商挂牌。按需价对应指定实例，现货可中断。Together、Lambda 1-Click、DigitalOcean、Verda 的预留价各有期限和数量条件。Azure 的期限折扣不保证容量。AWS Capacity Blocks 保证指定时段的容量，单独记录。CoreWeave、AWS EC2 的整机折算及 Azure、Verda 的计算式列在历史明细中。

第三方指数。Compute Desk／General Index 将美国成交与非超大云厂商牌价调整至一年期后平滑。本文署名引用 2026-11-25 单次读数。Silicon Data 的 neocloud 指数将不同地区、规格与期限归一至按需基准。Ornn OCPI 则按卡数加权统计按需成交。Silicon Data 与 Ornn 的历史序列须经授权才能对外分发。Compute Desk 方法 · GX 使用条款 · Silicon Data（silicondata.com，Products → Silicon Index） · Ornn 文档 · Ornn 条款

CCIR 合约汇总。CCIR 按签约半年与租期分组，调整捆绑服务和预付，大单权重较高。9 月专题中的 11 笔 B300 原始订单可在上表按型号查看。其条款允许署名引用，系统抓取和转载历史须取得书面许可。期限表 · 逐单样本 · CCIR 数据条款

历史覆盖。历史报价取自 Wayback 价目页快照、厂商公告和有日期的公开价格目录。每个观察日只保留一个点，可在历史数值表查看出处和快照时间。其余挂牌按 UTC 逐日观察。累计 3 个不同观察日后，报价才会出现在对比表和走势图中。默认展示观察日最多的序列，观察日数相同时优先展示日期跨度较长的序列，相邻观察相隔超过一天时留白。棕色方点标出公告价格生效日，蓝色方点标出已披露的整机配置变更。公告生效日单独记录，不增加观察次数。Nebius 逐地区、逐 SKU 的可中断日均沿用已有归档，06.ai 回填与官方接口分别展示。Nebius 历史与方法
