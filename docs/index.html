数据修订

方法

口径历史

  • 数据来源：Ramp AI Index 的公开周度接口 ramp.com/data/ai-index/chart-data/tokenVolumes提供每周 token 支出与用量指数。数据来自接入 Ramp AI 支出管理产品的企业，包括直连 API，以及经 AWS、GCP、Azure 和多家路由、推理平台的消费。Ramp 注明这部分不代表其全部 AI 支出。
  • 厂商指数。拼接时，每周优先取完整的官方厂商指数。同等精度下保留当周生效的版本。2026 年 11 月 2 日起，按模型的厂商归属汇总。选择「新口径全历史」可查看 Ramp 最新修订的历史序列。
  • 跨口径的四周窗口。同一口径下，份额按窗口内的指数合计计算。窗口横跨两种口径时，取各周份额的算术平均。支出、用量、增速和单位支出均先按各周系数换算；跨口径比较模型支出或单位支出时，按各模型每周在 Anthropic 内的份额分摊厂商支出和用量。
  • 美元和 token 估算。本站用 11 月 4 日存档的绝对金额和 token 数校准当前指数。旧数据按周六至周五统计，当前数据按周一至周日统计。将两者的周数据均摊到每天，再按自然月汇总。每次构建都用 2026 年 1–9 月全体厂商的存档总量除以同期指数总和，分别得到支出和用量的换算系数。单月偏差按当月估算值除以存档值再减一计算。单个厂商、单周和校准期之后的估算精度仍未知。
  • 单位 token 支出。将校准后的支出除以用量即可估算每百万 token 支出。Ramp 看板另行公布混合单价，原值见上表。
  • 周的定义：周一到周日，按周日日期标注，和 Ramp 看板的「Week ending」一致。
  • 修订：企业接入新的模型供应商后，Ramp 会回补其历史数据。本站每次检测到接口数据变化都保存一份原始快照，并对比 Anthropic 份额在各周的变化。
  • 覆盖范围：样本是 Ramp 的美国企业客户，不含消费者订阅、海外客户和大型直签合同，不能直接换算为 Anthropic 全公司收入或 ARR。
  • 更新：GitHub Actions 每天检查一次接口，数据有变化才重新构建。
